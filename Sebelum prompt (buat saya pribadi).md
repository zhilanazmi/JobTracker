
## Sebelum menjalankan prompt ini (dikerjakan manual, 5 menit)

1. Simpan file desain di repo sebagai `design/job-manager.pen`. Kalau nama atau lokasinya berbeda, ganti path di prompt.
2. Buka file `.pen` itu di pen.dev (desktop app atau ekstensi IDE). Server MCP-nya hanya aktif selama dokumen terbuka.
3. Di pen.dev: **Settings (⚙️) → MCP → aktifkan Claude Code CLI**.
4. Jalankan `claude` dari root repo, lalu ketik `/mcp`. Lanjut hanya kalau `pencil` berstatus **connected**.
5. Pastikan Docker jalan (untuk MySQL) dan Node 22 terpasang.
6. Tempel seluruh isi blok PROMPT di bawah ke Claude Code, dalam satu pesan.
